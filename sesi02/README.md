
# Product & Profile - PPM Sesi 2

Aplikasi Flutter sederhana untuk menampilkan profil mahasiswa
dan produk dengan fitur interaktif.

## Fitur
- Kartu profil mahasiswa dengan lima bintang.
- Kartu produk dan kategori.
- Tombol favorite dan jumlah like.
- Pengaturan kuantitas dan total harga.
- Tombol tambah ke keranjang dengan SnackBar.
- Banner promo menggunakan Stack dan Positioned.
